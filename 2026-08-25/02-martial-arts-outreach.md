## Hipótesis comercial que estamos validando

No vender “páginas web para gimnasios”.

Vender un sistema de negocio sencillo y visual que mejore la conversión:

**Consulta → Prueba → Alumno**

Para centros con muchas disciplinas, añadir:

**Consulta → Clasificación → Actividad adecuada → Prueba → Alumno**

La primera conversación debe generar curiosidad y permiso para enseñar el concepto. No presentar todavía un catálogo de servicios, CRM, automatizaciones o IA.
