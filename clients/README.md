# Commercial client experiments

Esta carpeta documenta oportunidades comerciales reales utilizadas para generar ingresos, aprender workflows y detectar productos potencialmente repetibles.

Estos experimentos **no sustituyen automáticamente** la tesis principal del radar micro-SaaS. Un servicio solo se convierte en candidato de producto cuando existe evidencia repetida entre varios clientes.
